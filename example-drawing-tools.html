建立基准 → 贴合工具 → 沿边作图

教学模式
绘图板与工具橙色实线：当前作图边

练习目标 / 教学章节

    当前摆放评分 100 / 100

    按贴靠、基准方向与图纸范围即时评分，不累计扣分。

    操作工具

    点击或拖动工具进行选择。选中工具后，方向键微调位置；Shift + 方向键大步移动。丁字尺仅平移。

    实物操作：一手轻压定位，另一手沿边运笔；平移前抬笔。不要把图板上、下边当作丁字尺的导向边。

    二维几何教学示意；画线按钮模拟沿边运笔。15° = 45° − 30°，75° = 45° + 30°；角度指直线与水平线的较小夹角。接触判定含少量屏幕操作容差。
